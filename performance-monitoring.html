Performance Monitoring for PHOENIX RB

Designed a performance monitoring interface for a data storage management system that helps track and optimize storage performance in real-time

Overview

Project:PHOENIX RB is a data storage management system developed by Cotvec. It provides companies with reliable and efficient storage infrastructure that works with existing equipment — even outdated hardware.

Challenge

Problem

The PHOENIX RB application lacked a built-in storage performance monitoring section. This created several serious inconveniences:

  • Users couldn't fully assess the state of their infrastructure through the main system interface.
  • Without built-in visualization, it was difficult to compare the performance of different LUNs and identify bottlenecks.
  • The absence of clear graphs made it hard to respond quickly to storage issues.
Objective

Create a built-in performance monitoring interface that transforms complex storage metrics into an intuitive, easily scannable dashboard with the ability to compare multiple LUNs simultaneously.
